The Anatomy

Four signals, one quiet band

Reads left to right from what changes every turn to what changes slowly. It shows figures without clutter, giving you instant awareness of budget and context pressure.

Context Window

Usage bar, percentage and used/window tokens. Pre-response estimate marked ~.

7-Turn Growth

Sparkline of recent turn additions. Each bar is colored by its share of the window to flag heavy turns.

5-Hour Quota

Percentage of the rolling 5-hour window used, with countdown ↻ to reset.

Weekly Quota

Weekly window with countdown. Follows the model family's own window (e.g. 7d fable) when reported.

Prompt Cache

warm with remaining minutes, or cold. Avoids costly 1.25× cache rewrites after pauses.

Built for focused Claude Code sessions

Context at a glance

Percentage and token counts. Before the first response or after /clear, it shows Claude Code's estimate instead of a blank.

Each turn's growth

Seven-bar sparkline of recent context additions. Each bar colored by its share of the window, so a heavy diff or dump stands out.

Quota & reset countdowns

The 5-hour and weekly windows side by side, with exact time until each resets. Dimmed when remembered from a previous session.

Prompt-cache warmth

Know whether the last request hit the prompt cache and how many minutes it remains warm before expiring.

One color scale

Ten tiers from cool to warm. Cool is safe, yellow is caution, warm to red is warning. Red-green color-blind accessible.

Zero telemetry, pure privacy

Only reads numbers Claude Code already exposes. No network requests, no model requests, no background processes.

Design System

The ten-tier cool-to-warm scale

Instead of green-yellow-red which fails for red-green color-blind users, ccOverhead walks smoothly from indigo through sky, cyan, teal and lime into amber and red.

Red-Green Accessible

Under protanopia and deuteranopia simulations, cool tiers (0–4) and warm tiers (7–9) maintain at least ΔE 17 perceptual distance.

Logarithmic Growth Tiers

Growth tiers double from 0.1% of the window. Everyday turns stay cool, while rare heavy turns (e.g. 64k+ dumps) immediately flash warm.

Graceful Narrowing

On narrow terminals, secondary details yield first: chart, then cache, then token numbers, keeping context visible the longest.

Install in seconds

ccOverhead is distributed via Claude Code's official plugin marketplace system.

  1. Add marketplace

    Register the repository as a plugin marketplace in Claude Code:

    /plugin marketplace add shengyy/ccoverhead

  2. Install plugin

    Install the ccOverhead mod from the newly registered marketplace:

    /plugin install ccoverhead@ccoverhead

  3. Reload

    Apply the hooks into your active session:

    /reload-plugins
Updating and uninstallation commands

To update to the latest release:

/plugin marketplace update ccoverhead
/plugin update ccoverhead@ccoverhead
/reload-plugins

To uninstall:

/plugin uninstall ccoverhead@ccoverhead
/reload-plugins

Frequently asked questions

Does ccOverhead make network requests or consume API tokens?

No. ccOverhead makes zero network requests, zero file reads, zero background processes, and zero model calls. It only reads the usage and limit numbers that Claude Code's mod system already reports into memory.

Which Claude Code versions are supported?

Claude Code 2.1.288 or later with mods (function-hook plugins) support. Verified versions are maintained in docs/status.md.

Why does the band look different in Terminal and Desktop?

The terminal uses monospace block glyphs (■□, ▁▂▃) for context and sparklines. In the Claude desktop app, which uses proportional typography, ccOverhead renders crisp vector Svg elements and native Box layouts to ensure perfect pixel alignment.

How does the prompt cache warmth indicator work?

ccOverhead monitors request events. When a request reads or writes the cache, it tracks warmth over its 1-hour lifetime (the ephemeral_1h cache window). If no subsequent query occurs before the window runs out, the status turns cold.

What happens on narrow terminal windows?

The band gracefully narrows in six discrete stages: it first drops the growth sparkline, then the cache group, then token counts, followed by weekly and 5-hour countdown timers, preserving the essential context indicator longest.
