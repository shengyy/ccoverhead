A cache rewrite

See the rewrite, not just the warmth.

When a turn reads less than half of the previous input from cache, rewrote shows the tokens written again. The first request after compaction builds a fresh prefix and does not count as a rewrite.

A subagent’s transcript

The context follows the agent.

Open a subagent’s transcript and ctx becomes agent. Its context and growth take the first group; cache and quota keep their main-conversation and account meanings.

On resume. Warmth is aged from the transcript’s last response, so a pause carries through to the cache state.

On a narrow window. The chart, cache rewrite and secondary figures yield in stages. Context stays visible longest.

These previews use fictional data. The latest states have test and render coverage; live visual checks are still pending. Read the verification notes.

A consistent visual language

Cool when there’s room.
Warm when it matters.

One ten-step scale for context, quota, cache age and growth. The numbers stay readable without relying on color alone.

A few useful answers

Before you install.

Does the mod send data or use model tokens?

No. It reads figures Claude Code already reports, without network or model requests, file access, or background processes. Session figures stay in memory; only the last quota reading is saved in Claude Code’s plugin store. Privacy details.

Where do the band and the pane appear?

The band appears in the terminal and the Claude desktop app’s Code tab. The /ccoverhead pane targets every Claude Code surface, including VS Code and mobile. The latest pane and band additions have test and render coverage; live visual checks are pending. Verified surfaces and versions.

Why does the context sometimes have a ~?

Before the first response, after /clear, or after compaction, ~ marks Claude Code’s local estimate. The next response replaces it with a reported total. If an estimate is unavailable, the band shows -- instead of an old reading.

What about model-specific quota or gateway limits?

When Claude Code reports a weekly window for the main model, the weekly group follows it, for example 7d fable. A gateway’s spend_limit appears as spend and can exceed 100%. Both paths are covered by synthetic tests and have not yet been verified with live readings. Without them, the regular weekly window stays in use.

Are quota and cache readings cost estimates?

No. Quota is a share used, not a bill or a prediction. The pane puts time elapsed beside usage without projecting when you will run out. Cache warmth reflects the main conversation’s reported reads and writes; ccOverhead never pauses, compacts or changes a model for you.

Does it work with a light theme?

The previews use a dark theme. Desktop graphics include a light palette, but text colors are tuned for dark surfaces and light themes have not been verified live. Current verification limits.
